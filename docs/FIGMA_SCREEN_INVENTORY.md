# Figma screen inventory

Source: Figma file `Local-WorkMan` (`7Ve4UcfOrOcbrPh0eoomRn`), page **Final** (node `68:8827`, a 46,767 x 26,200 canvas holding every screen). The page is laid out as three role rows (labelled by text nodes `Candidate`, `Recruiter`, `Admin`); within a row, frames run left-to-right in flow order and carry a numeric suffix (e.g. `Overview_3`).

- **Roles discovered:** Candidate (job seeker), Recruiter (employer), Admin - each has its own sign-in frame and sidebar. No role or screen was assumed beyond these frames.
- **Responsive variants:** none. Every frame is a 1440 px desktop design (heights 1024-2668 px). No tablet or mobile frames exist in the file; responsive behaviour below 1024 px is an adaptation (see `DESIGN_SYSTEM.md`).
- The older **Work Space** page contains earlier duplicates of the same screens; it was not used. The **D S** page holds the design system (see `DESIGN_SYSTEM.md`).
- Statuses: `Not started` -> `Built` (implemented, build passes) -> `Visually checked` (browser render compared with the Figma screenshot). Updated after each batch.
